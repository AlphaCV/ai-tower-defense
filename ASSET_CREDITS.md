# Asset sources

The presentation uses original PNGs from Kenney Tower Defense (Top-Down).

- Author: Kenney Vleugels (Kenney.nl)
- Original page: https://kenney.nl/assets/tower-defense-top-down
- Download: https://kenney.nl/media/pages/assets/tower-defense-top-down/729844df28-1677693738/kenney_tower-defense-top-down.zip
- License: CC0-1.0. Original license is retained at ai_gym_td/assets/kenney/License.txt.
- Archive SHA256: 08fb8d73af19062d56dd00e91935cfd1638229723deaa32e6c1800e1ba6d442d
- Per-file names and uses: ai_gym_td/assets/manifest.json.
- Original PNG bytes are unchanged; runtime scaling, rotation, enemy transparent-padding normalization and grass color modulation adapt them to the grid.
- Panels, borders, status icons and type markers are drawn in Pygame by this project.
- Fonts: Chinese UI reads installed Microsoft YaHei on Windows (with installed CJK font fallbacks on other systems). No system font files are copied or redistributed. Pygame bundled font remains the last-resort fallback with a warning.

Defending Todot and Unity Tower Defence were design references only.
No Godot/Unity code, proprietary images, or audio from those repositories was copied.
